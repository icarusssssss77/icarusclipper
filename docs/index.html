clipper

clipper is a personal, self-hosted tool. It finds highlight moments in gaming livestreams, edits them into vertical short videos with captions, and uploads them to its owner's own YouTube channel.

It is not offered to the public. The only account that signs in is the channel owner's.

YouTube API Services

clipper uses YouTube API Services to upload videos to the owner's channel. By using clipper you agree to the YouTube Terms of Service.
