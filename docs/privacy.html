Privacy Policy

Last updated: November 19, 2026

clipper is a personal tool used only by the owner of the connected YouTube channel.

YouTube API Services

clipper uses YouTube API Services. By using clipper you agree to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

What data clipper accesses

  • One permission: https://www.googleapis.com/auth/youtube.upload, used only to upload videos and set their title, description and tags on the owner's channel.
  • clipper does not read your YouTube watch history, subscriptions, comments, analytics, email or contacts.

How it is used and stored

  • The OAuth access and refresh tokens are stored only on the owner's private server, in a file that is never published.
  • Video IDs returned by YouTube after an upload are kept in a local log so the tool doesn't post the same clip twice.
  • No cookies, analytics or tracking are used on this website.

Sharing

clipper does not sell, share or transfer any user data to third parties.

Deletion and revoking access

  • You can revoke clipper's access at any time from Google security settings (myaccount.google.com/permissions).
  • Deleting the token file on the server removes all stored YouTube credentials immediately. Stored data is deleted within 7 days after access is revoked.

Contact

Questions: open an issue at github.com/icarusssssss77/icarusclipper/issues.

clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
